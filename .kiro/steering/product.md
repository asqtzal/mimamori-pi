# Product Overview

## Product Vision & Mission
**Vision**: 新生児の環境を最適化し、将来のスマートハウス化を見据えた拡張可能なIoTモニタリングシステム

**Mission**: 技術的知識に関係なく、すべての親が赤ちゃんの快適で安全な環境を維持できるよう支援する

## Target Users
- **Primary**: 新生児を持つ親
- **Secondary**: 一般家庭でのIoT環境構築を目指すユーザー
- **Future**: スマートハウス愛好者、IoT開発者

## Core Values
- **安心**: 24時間のビデオモニタリングで赤ちゃんの様子を確認
- **利便性**: LAN内のあらゆるデバイスから簡単アクセス
- **拡張性**: 将来的な機能追加やクラウド連携への対応
- **信頼性**: 堅牢な設計による長期間の安定稼働

## Key Features

### Phase 1（MVP）
- **リアルタイムストリーミング**: LAN内でのビデオストリーミング閲覧
- **カメラ制御**: 開始/停止、回転設定
- **スナップショット保存**: 定期的な静止画自動保存
- **履歴閲覧**: 保存された画像の一覧表示・閲覧
- **システム監視**: カメラ状態、ストレージ使用量の確認

### Phase 2（将来拡張）
- **リモートアクセス**: VPNまたはクラウド経由での外部アクセス
- **クラウドストレージ**: AWS S3等への画像アップロード

### Phase 3（将来拡張）
- **姿勢検知**: 機械学習によるうつ伏せ検知
- **アラートシステム**: 危険姿勢検出時の通知
- **データ分析**: 睡眠パターンの可視化
